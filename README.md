# Capstone Dealership App

Repository: `capstone-dealership-app`

Project name: **Capstone Dealership App**, a full-stack car dealership web application.

- **Backend:** Django (`server/djangoapp`, `server/djangoproj`) for dealers, reviews, login, and registration.
- **Data API:** Node.js + Express + MongoDB (`server/database`).
- **Sentiment analysis:** Flask microservice (`server/djangoapp/microservices`).
- **Frontend:** React (`server/frontend`) and static HTML pages (`server/frontend/static`).
- **Deployment:** Docker and Kubernetes (`server/Dockerfile`, `server/deployment.yaml`).
- **Submission:** cURL outputs and screenshots in `submission/`.
